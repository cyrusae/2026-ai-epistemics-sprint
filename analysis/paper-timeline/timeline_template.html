Replication run timelines

Twenty fresh Feynman 0.5.65 sandbox sessions (DeepSeek V4.1 Flash) asked to work on the same paper. seq runs got three prompts in one session: audit the paper, then replicate it, then "create an isolated venv first". repl runs got only the last two. Each block is one run, its turns back to back; the lead agent's model and tool calls on top, sub-agent sessions below. Hover any mark for details.

Table view

Model call = one request to the model (start to end of the response). Tool call = execution time of a tool, including a subagent or bg_wait call that blocks until sub-agents finish. Gaps in the lead bar are harness bookkeeping. Time 0 is the human's first message. A run with a follow-up prompt shows its turns back to back, separated by a dashed line; the hours of idle time before the human's reply are left out. Source: session logs in each run's state/.feynman/sessions/, extracted by timeline.py.
