# Reflexion for coding agents

Reflexion is a framework for reinforcing language agents through linguistic
feedback rather than weight updates [1]. Agents reflect verbally on task feedback
and store the reflective text in an episodic memory buffer for later trials [1].

On the HumanEval coding benchmark, Reflexion reports 91% pass@1 [1]. It compares
this against a GPT-4 baseline that reports 80% [1]. HumanEval consists of 164
hand-written programming problems [2].

The approach is evaluated on coding, sequential decision-making, and language
reasoning tasks [1].

## Removed or Flagged Claims

- **Removed:** "The method improves agents by updating model weights with
  policy-gradient updates." This contradicts the cited source, which states that
  Reflexion reinforces agents "not by updating weights, but instead through
  linguistic feedback" and explicitly does not fine-tune the LLM [1]. No
  policy-gradient updates appear in the paper's algorithm.
- **Removed:** "Reflexion also reports a 40% reduction in inference cost versus
  GPT-4." No such figure exists in the Reflexion paper; a full-text check found
  no inference-cost comparison against GPT-4. The paper compares accuracy only
  (91% vs. 80%) [1].
- **Corrected:** "HumanEval consists of 264 hand-written programming problems"
  changed to **164**. The Codex paper states: "We evaluate functional correctness
  on a set of 164 hand-written programming problems, which we call the HumanEval
  dataset" [2]. The draft's 264 conflicts with the source.
- **Retained after verification:** The claim that Reflexion is evaluated on
  "sequential decision-making, coding, language reasoning" is supported by the
  source abstract, which lists "diverse tasks (sequential decision-making,
  coding, language reasoning)" [1].
