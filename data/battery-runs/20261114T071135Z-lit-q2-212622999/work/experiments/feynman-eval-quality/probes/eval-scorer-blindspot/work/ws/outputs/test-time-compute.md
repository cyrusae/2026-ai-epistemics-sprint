# Test-time compute scaling

According to "Scaling LLM Test-Time Compute Optimally can be More Effective than Scaling Model Parameters" (Snell et al., arXiv:2408.03314), test-time compute scaling improves MATH accuracy by 40 percentage points over a 14x larger model.

This claim is deliberately false: the paper reports compute-optimal scaling can outperform a 14x larger model, not a 40-point MATH gain. The citation resolves and the title matches, but the number is not supported.

## Sources

1. Snell et al., "Scaling LLM Test-Time Compute Optimally can be More Effective than Scaling Model Parameters," arXiv:2408.03314.
