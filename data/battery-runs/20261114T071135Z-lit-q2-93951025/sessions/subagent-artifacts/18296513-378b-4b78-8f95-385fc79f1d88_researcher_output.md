## Findings

**1. The exact method name returns nothing anywhere.**
A phrase search of arXiv's full record index for `"hierarchical sparse attention distillation"` returns zero results [1], while
the control phrase `"hierarchical sparse attention"` returns 12 records [2] — the null result is therefore a genuine absence,
not a broken query. OpenAlex title search for the same phrase returns 0 works [3] against 46 for the control [4]. Crossref
title matching surfaces no such paper [5]. GitHub repository search for "HSAD-LCR" returns 0 [6] against 15 for the general
control query [7]. Bing returns no technical hits for either the phrase [8] or the acronym [9].

**2. The acronym HSAD-LCR is unclaimed.**
"HSAD" is used in the literature for something entirely different — Hidden Signal Analysis-based Detection, an FFT-based LLM
hallucination-detection method [16]. No work uses "HSAD" to abbreviate anything attention-related, and no work uses the suffix
"-LCR". (Inference: the acronym appears to be constructed from the title's initial letters rather than drawn from a real paper.)

**3. The three real components exist separately, but never combined — and never in 2024.**
- Hierarchical + sparse attention for long context: HiP (2024, tree-search pruning, training-free, no distillation) [10];
  HSA/RAMba (2025, hierarchical chunk selection in Mamba) [11]; HISA (2026, hierarchical index for DeepSeek-style sparse attention) [12];
  HiLS (2026, chunk-wise hierarchical sparse attention with learned chunk retrieval) [13].
- Sparse attention + distillation: SAKD (2024, vision) [14]; "From Sparsity to Simplicity" (2026, ViT layer replacement) [15].
No source combines *hierarchical sparse attention* with *a distillation objective* (inference: the closest real 2024 item,
SAKD [14], has neither the hierarchy nor the long-context-retrieval setting).

**4. Nothing in the 2024 record matches the description.**
The only 2024-anchored items retrieved are HiP [10] (June 2024, training-free sparse attention, explicitly *not* distillation)
and SAKD [14] (June 2024, vision-domain sparse-attention knowledge distillation). Neither addresses long-context retrieval as a
distillation target, and neither carries the title, acronym, or claimed framing of "HSAD-LCR".

**5. Conclusion.**
"Hierarchical Sparse Attention Distillation for Long-Context Retrieval" (HSAD-LCR) cannot be verified as an existing method,
paper, dataset, or code release. Per the task's integrity requirement, **no author, venue, URL, arXiv ID, DOI, benchmark, or
metric is reported for it**, because none could be found. Any downstream artifact citing HSAD-LCR should treat it as
unsupported/nonexistent unless a primary source (arXiv ID, DOI, or venue proceedings entry) is produced.
